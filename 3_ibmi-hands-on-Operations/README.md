# IBM Bob 運用編ハンズオン へようこそ 🛠️

IBM Bob と IBM Bob Premium Package for i（PP4i）を実際の IBM i 実機環境に接続し、**IBM i の運用・保守業務**を生成AIで効率化・高度化する方法を学ぶハンズオンです。

開発編（[1_ibmi-hands-on-JPAN-TechSales](../1_ibmi-hands-on-JPAN-TechSales/README.md)）が「RPG を読む・直す・作る」にフォーカスしているのに対し、運用編では **「実機の資産を把握する・システムやジョブの稼働状態を可視化する・止まっているジョブを検知して安全に復旧する」** という、運用担当者・システム管理者の日常業務を Bob と PP4i（IBM i 接続機能）で体験します。

## 🎯 ワークショップ概要

### 学べること

- ✅ RPG/CL 資産の棚卸しと「運用者向け」プログラム説明書の作成
- ✅ IBM i Services（SQL）を使ったサブシステム・ジョブの可視化
- ✅ 「本来動いているべきジョブ」との突合せによる停止ジョブの検知
- ✅ 停止原因の調査と、**人が承認してから**ジョブを再起動する運用フロー
- ✅ Rules による「AIにやらせてよいこと・ダメなこと」の制御

### 対象者

- 🎯 **IBM i 運用担当者** - 日次の稼働確認・障害一次対応を効率化したい
- 🎯 **IBM i システム管理者** - サブシステム・ジョブ管理を見える化したい
- 🎯 **保守担当者** - 担当外のRPG資産を短時間で把握したい
- 🎯 **PP4i 購入済みのお客様** - 開発以外での活用方法を知りたい

- ✅ **IBM Bob アカウント**（PP4i のシートが割り当て済みであること）

  - 専用の作業ライブラリー `STUDYxx`（QEOL サンプル資産の複製）

- ハンズオン用共通サブシステム `HANDSON` および共通環境が講師によりセットアップ済み（詳細は [`instructor/講師用準備ガイド.md`](./instructor/講師用準備ガイド.md) を参照）

## 📚 ワークショップの構成

### 0️⃣ 準備

### 1️⃣ LAB1-OPS: 資産の見える化 📦

「このライブラリーに何があって、何が使われていて、どれとどれがつながっているのか」を Bob に調べさせます。最後に、**障害時に運用者が読むための「プログラム説明カード」**を作成します。

📝 [LAB1-OPSを始める](./LAB1-OPS.md)

### 2️⃣ LAB2-OPS: ジョブ／サブシステムの見える化 🖥️

`WRKSBS` / `WRKACTJOB` / `WRKJOBSCDE` で見ていた情報を、自然言語で Bob に聞きます。応答待ち（MSGW）のジョブや未回答の QSYSOPR メッセージを洗い出し、**稼働状況レポート（HTML）**にまとめます。

📝 [LAB2-OPSを始める](./LAB2-OPS.md)

「本来動いているべきジョブ」を期待値テーブルとして定義し、実際の稼働状況と突き合わせます。止まっているジョブを見つけたら原因を調べ、**Bob が起動コマンドを提案 → 人が承認 → 実行 → 再確認**という運用フローを体験します。

📝 [LAB3-OPSを始める](./LAB3-OPS.md)

### 4️⃣ LAB4-OPS: 毎朝の稼働チェックを定型化（オプション） 🔁

LAB1〜3 で使ったプロンプトをテンプレート化し、毎朝ワンアクションで稼働チェックできる形にします。

## 🛡️ このハンズオンの安全設計

運用部門で AI を使う際に最も重要なのは **「AI が勝手に実行しない」** ことです。このハンズオンでは次の仕組みでそれを担保します。

| 仕組み | 内容 |
|-------|------|
| **ツール実行の承認** | Bob が CL コマンドや更新系 SQL を実行する前に、必ず承認ボタンでの確認を求めます |
| **Rules（[ops-safety.md](./.bob/rules/ops-safety.md)）** | 参照系は自由・更新系は事前提示と承認必須・`PWRDWNSYS` や `ENDSBS` 等の危険コマンドは禁止、を Bob に常時守らせます |
| **権限の分離** | ハンズオン用ユーザーは、自分が投入したジョブ以外は操作できない権限で実施します |
| **専用サブシステム** | 起動・停止の練習はハンズオン専用サブシステム `HANDSON` 内だけで行います |

> ⚠️ **本番環境では実施しないでください。** 検証区画またはハンズオン専用区画で実施してください。
